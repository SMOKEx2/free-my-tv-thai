# Free My TV Thai 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Publish a private-data-free 2.0 repository with a bundled Windows installer and detailed English AI installation guide.

**Architecture:** Keep the existing native Java app. Add pure Java policies for shelf pagination and package recovery, and standard-library Python tooling for builds, user choices, backups, and recovery. Ship a portable Windows x64 tool archive with verified hashes and notices.

**Tech Stack:** Java 8 source / JDK 17, Android API 34 / minSdk 28, Python standard library, PowerShell, ADB.

**Spec:** `docs/superpowers/specs/2026-10-21-version-2-design.md`

## Global Constraints

- Version 2.0, versionCode 2; preserve io.freemytv and upstream MIT notices.
- Never publish personal keys, configs, signing material, device IDs, backups, or personalized APKs.
- Bundle actual Windows x64 tools; keep each tracked file under 100 MB.
- Ad cleanup is optional, Xiaomi-only, exact-ID, reversible, and preserves essential services.
- All public setup and AI documentation is English; app supports Thai and English.

## Review Focus

- Existing disabled packages must remain disabled after restore.
- More than seven chosen apps must remain reachable without tiny or overlapping dock tiles.
- Spaces and quotes in paths/config and non-ASCII city names must survive generation/build.
- ADB offline, unauthorized, multiple devices, and installation signature mismatch must stop safely.
- A partial activation/restore must retain enough state to recover after process interruption.
